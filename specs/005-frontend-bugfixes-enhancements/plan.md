# Implementation Plan: Frontend Bug Fixes & Enhancements

**Branch**: `005-frontend-bugfixes-enhancements` | **Date**: 2025-12-17 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/005-frontend-bugfixes-enhancements/spec.md`

## Summary

Fix 7 frontend bugs (duplicate headers, chat overlap, modal blur, hover states, theme inconsistency, loading states, instant chat history) and enhance the chat interface to modern ChatGPT-style layout with sidebar. Additionally, synchronize theme between frontend and Docusaurus book iframe, and update documentation to reflect actual implementation.

**Storage**: PostgreSQL Neon DB via Drizzle ORM (existing schema)
**Testing**: Vitest, @testing-library/react
**Target Platform**: Web (Next.js App Router)
**Project Type**: Web application (frontend + backend separation)
**Performance Goals**: Theme toggle < 300ms, hover feedback < 50ms, loading indicators < 100ms
**Constraints**: No backend API changes, Docusaurus book must implement theme parameter reading
**Scale/Scope**: Frontend bug fixes affecting ~15 files, documentation updates affecting ~5 files
